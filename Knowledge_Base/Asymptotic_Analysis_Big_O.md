# Asymptotic Analysis (Big O)
Asymptotic analysis is a method of describing the [[Complexity]] of an [[Algorithm]] as the size of the input increases. It is commonly referred to as Big O notation.

## Overview
Asymptotic analysis is used to analyze the performance of an algorithm, focusing on its worst-case scenario. It provides an upper bound on the number of steps an algorithm takes, relative to the size of the input. Big O notation is a way to describe the upper bound of an algorithm's complexity, usually in terms of the size of the input, denoted as 'n'. The most common complexities are:
- [[O(1)]] (constant time)
- [[O(log n)]] (logarithmic time)
- [[O(n)]] (linear time)
- [[O(n log n)]] (linearithmic time)
- [[O(n^2)]] (quadratic time)
- [[O(2^n)]] (exponential time)
- [[O(n!)]] (factorial time)

## Concept Map
The concept map for asymptotic analysis includes the following key terms:
- [[Algorithm]]: a set of instructions for solving a problem
- [[Complexity]]: the amount of resources (time or space) required to solve a problem
- [[Big O notation]]: a way to describe the upper bound of an algorithm's complexity
- [[Time complexity]]: the amount of time an algorithm takes to complete
- [[Space complexity]]: the amount of memory an algorithm uses
- [[Trade-off]]: the balance between time and space complexity in an algorithm
- [[Optimization]]: the process of improving an algorithm's complexity
