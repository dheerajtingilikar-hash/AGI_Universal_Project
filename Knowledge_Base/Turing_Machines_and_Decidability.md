# Turing Machines and Decidability
## Overview
Turing Machines and Decidability is a fundamental concept in the field of [[Computer Science]], specifically in the area of [[Theory of Computation]]. It deals with the study of [[Turing Machines]], which are mathematical models used to describe the concept of [[Algorithms]] and [[Computability]]. The decidability of a problem refers to whether it can be solved by a Turing Machine in a finite amount of time.

## Concept Map
The concept of Turing Machines and Decidability can be broken down into the following key areas:
* [[Turing Machines]]: a mathematical model for computation that consists of a [[Tape]] and a [[Head]] that can read and write [[Symbols]] on the tape.
* [[Decidability]]: a problem is decidable if there exists a Turing Machine that can solve it in a finite amount of time.
* [[Undecidability]]: a problem is undecidable if there does not exist a Turing Machine that can solve it in a finite amount of time.
* [[Halting Problem]]: a famous undecidable problem that deals with determining whether a given Turing Machine will halt on a given input.
* [[Reducibility]]: a technique used to show that a problem is undecidable by reducing it to a known undecidable problem.

## Key Results
* The [[Halting Theorem]] states that the halting problem is undecidable.
* The [[Rice's Theorem]] states that any non-trivial property of a Turing Machine is undecidable.
* The [[Church-Turing Thesis]] states that any effectively calculable function can be computed by a Turing Machine.
