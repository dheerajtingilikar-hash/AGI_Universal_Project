# Algebraic Topology
Algebraic topology is a branch of [[Mathematics]] that uses [[Algebra]]ic tools to study the properties of [[Topological Space|topological spaces]].

## Overview
Algebraic topology is a field of study that combines [[Topology]] and [[Abstract Algebra]] to analyze the properties of shapes and spaces. It provides a framework for studying the topological properties of spaces using algebraic invariants, such as [[Homotopy Group|homotopy groups]] and [[Homology|homology groups]]. These invariants can be used to distinguish between different topological spaces and to study their properties.

## Concept Map
The key concepts in algebraic topology include:
* [[Homotopy Theory|Homotopy theory]], which studies the properties of [[Continuous Function|continuous functions]] between topological spaces
* [[Homology|Homology theory]], which studies the properties of [[Topological Space|topological spaces]] using algebraic invariants
* [[Cohomology|Cohomology theory]], which is a dual theory to homology
* [[Betti Number|Betti numbers]], which are used to describe the properties of topological spaces
* [[Euler Characteristic|Euler characteristic]], which is a topological invariant that describes the properties of a space
* [[Fundamental Group|Fundamental group]], which is a group that encodes the properties of a topological space

Related topics include:
* [[Differential Topology|Differential topology]], which studies the properties of [[Smooth Manifold|smooth manifolds]]
* [[Geometric Topology|Geometric topology]], which studies the properties of [[Low-Dimensional Topology|low-dimensional manifolds]]
* [[Category Theory|Category theory]], which provides a framework for studying the properties of mathematical structures.
