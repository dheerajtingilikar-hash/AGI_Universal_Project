# Computer Architecture
## Overview
Computer architecture refers to the design and organization of a [[Computer]]'s internal components, including the [[Central Processing Unit]] (CPU), [[Memory]], and [[Input/Output]] (I/O) systems. It encompasses the study of the fundamental principles and concepts that govern the structure and behavior of computer systems. Computer architecture is a crucial aspect of [[Computer Science]] and [[Computer Engineering]], as it determines the performance, efficiency, and scalability of computer systems.

## Concept Map
The concept of computer architecture can be broken down into several key areas, including:
* [[Instruction Set Architecture]] (ISA): defines the set of instructions that a CPU can execute
* [[Microarchitecture]]: describes the internal organization and operation of the CPU
* [[Memory Hierarchy]]: refers to the organization of [[Cache Memory]], [[Main Memory]], and [[Secondary Storage]]
* [[Parallel Computing]]: involves the use of multiple processing units to improve performance and efficiency
* [[Interconnection Networks]]: provide communication pathways between different components of a computer system

## Key Components
* [[CPU]]: executes instructions and performs calculations
* [[Memory]]: stores data and program instructions
* [[I/O Systems]]: manage input and output operations between the computer and external devices
* [[Bus (Computing)]]: provides a communication pathway between different components of a computer system

## Related Fields
* [[Computer Networks]]: deals with the communication and interaction between multiple computer systems
* [[Operating System]]: manages computer hardware resources and provides a platform for running applications
* [[Embedded Systems]]: refers to the use of computer systems in specialized devices and applications
