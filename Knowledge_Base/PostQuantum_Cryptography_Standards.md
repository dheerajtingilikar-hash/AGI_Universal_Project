# Post-Quantum Cryptography Standards

## Overview

Post-quantum cryptography standards are cryptographic protocols designed to be resistant to attacks by both classical and quantum computers. The need for post-quantum cryptography arises from the potential for a large-scale quantum computer to break many existing cryptographic algorithms, compromising the security of sensitive information.

### Key Standards

- **NIST PQC**: The National Institute of Standards and Technology (NIST) has launched a process to standardize post-quantum cryptographic algorithms. The process involves a competition to select the most secure and efficient algorithms.
- **SPHINCS**: A post-quantum digital signature scheme based on hash functions.
- **FrodoKEM**: A post-quantum key encapsulation mechanism (KEM) based on the learning with errors (LWE) problem.
- **New Hope**: A post-quantum key encapsulation mechanism (KEM) based on the Ring Learning With Errors (Ring-LWE) problem.
- **Kyber**: A post-quantum key encapsulation mechanism (KEM) based on the Ring Learning With Errors (Ring-LWE) problem.
