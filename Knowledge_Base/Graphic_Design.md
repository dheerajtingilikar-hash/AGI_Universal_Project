# Graphic Design
Graphic design is the art and practice of communicating ideas and messages through visual and textual content. It involves a combination of [[Typography]], [[Color Theory]], and [[Composition]] to create visual elements such as [[Logos]], [[Icons]], and [[Graphics]].

## Overview
Graphic design is a multidisciplinary field that incorporates various techniques and tools to create visual communications. It is used in a wide range of applications, including [[Advertising]], [[Branding]], and [[Publishing]]. Graphic designers use computer software such as [[Adobe Creative Suite]] to create and edit visual elements.

## Concept Map
The concept map of graphic design includes:
* [[Visual Identity]]: The visual elements that represent a brand or organization, such as [[Logos]] and [[Color Schemes]].
* [[Page Layout]]: The arrangement of text and images on a page to create a clear and effective design.
* [[User Experience]]: The interaction between the user and the design, including [[Navigation]] and [[Information Architecture]].
* [[Design Principles]]: The fundamental principles that guide the design process, including [[Balance]], [[Contrast]], and [[Emphasis]].

## Key Terms
* [[Design Thinking]]: A problem-solving approach that involves empathy, ideation, and experimentation.
* [[Graphic Design Software]]: Computer programs used to create and edit visual elements, such as [[Adobe Photoshop]] and [[Adobe Illustrator]].
* [[Design Systems]]: A set of standardized components and guidelines used to create consistent designs across multiple applications.
