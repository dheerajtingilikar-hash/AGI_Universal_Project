# Elliptic Curve Cryptography
Elliptic Curve Cryptography (ECC) is a type of [[Public-Key Cryptography]] that is based on the [[Mathematics]] of [[Elliptic Curves]]. It is a key agreement protocol that allows two parties to establish a shared secret key over an insecure communication channel.

## Overview
ECC is a cryptographic technique that is used to secure online transactions, communications, and data. It is based on the difficulty of the [[Elliptic Curve Discrete Logarithm Problem]] (ECDLP), which is a mathematical problem that is difficult to solve. ECC is considered to be a more secure and efficient alternative to other public-key cryptosystems, such as [[RSA]].
