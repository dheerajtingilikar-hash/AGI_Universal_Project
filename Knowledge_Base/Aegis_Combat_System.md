# Aegis Combat System

## Overview

The Aegis Combat System is a [[Radar]] and [[Missile Defense]] system developed by the United States Navy. It is designed to detect, track, and engage incoming threats, such as ballistic missiles, aircraft, and other naval vessels. The system is integrated into the [[Aegis Cruiser]] and [[Aegis Destroyer]] classes of ships.

### Components

- **SPY-1 Radar**: A [[Phased Array Radar]] system used for detection and tracking of targets.
- **AN/SPY-1B Radar**: An upgraded version of the SPY-1 Radar with improved performance and capabilities.
- **AN/SPY-1D Radar**: A further upgraded version of the SPY-1 Radar with enhanced performance and capabilities.
- **AN/SPY-1F Radar**: A variant of the SPY-1 Radar used on the [[Littoral Combat Ship]].
- **Standard Missile (SM) Family**: A family of [[Surface-to-Air Missile]]s used for engaging targets.
- **Aegis Combat System Software**: A software suite used to operate and control the Aegis Combat System.
