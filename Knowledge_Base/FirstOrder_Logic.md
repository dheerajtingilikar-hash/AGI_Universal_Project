# First-Order Logic
First-Order Logic (FOL) is a branch of [[Mathematical Logic]] that deals with reasoning and [[Inference]] using [[Quantifiers]] and [[Predicates]].

## Overview
First-Order Logic is a formal system that allows for the expression of logical statements using [[Propositional Logic]] and [[Quantification]]. It provides a framework for representing and reasoning about [[Knowledge]] and [[Uncertainty]] in a rigorous and systematic way. FOL is widely used in [[Artificial Intelligence]], [[Computer Science]], and [[Philosophy]] to formalize and analyze complex systems and arguments.

## Concept Map
The key concepts in First-Order Logic include:
* [[Quantifiers]]: [[Universal Quantification]] (∀) and [[Existential Quantification]] (∃)
* [[Predicates]]: [[Propositional Functions]] that assign [[Properties]] to [[Objects]]
* [[Variables]]: [[Propositional Variables]] and [[Predicate Variables]]
* [[Terms]]: [[Constants]], [[Variables]], and [[Functions]]
* [[Formulas]]: [[Atomic Formulas]] and [[Compound Formulas]]
* [[Theorems]]: [[Logical Consequences]] of a set of [[Axioms]]
* [[Models]]: [[Interpretations]] of a First-Order Theory
